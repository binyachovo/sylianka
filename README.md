# Трафарет силянки

Програма для створення трафаретів силянок: сітка з ромбів, розфарбовування бісерин, підрахунок бісеру й друк.
Працює в браузері, встановлюється як програма (PWA) і працює без інтернету.

**Адреса:** https://binyachovo.github.io/sylianka/

## Що вміє зараз

- Каталог Preciosa 10/0 (круглий рокайль, артикули 311-19001 і 331-19001) — 1 372 кольори з кодами, українськими назвами й описом Preciosa. Пошук за кодом (напр. `23980`) або назвою, групи за кольором.
- Кольори трафарету для швидкого вибору: код видно біля кожного кольору — у панелі, у каталозі, у підрахунку й у підказці над бісериною.
- «Мої кольори»: свій відтінок, своя назва й необов'язковий код. Зберігаються для всіх трафаретів і потрапляють у файл трафарету.
- Режим плетіння: нанизану бісеринку позначають кліком або протягуванням мишею, порядок позначення — її номер у наборі. Нанизані приглушуються, остання підсвічена («Показати, де зупинилися»), лічильник «нанизано N з M», прогрес за кожним кольором, «Скасувати» й «Скинути позначки». Підказка над бісериною — номер, код і колір.
- Кілька трафаретів у списку «Мої трафарети»: новий, відкрити, перейменувати, дублювати, видалити. Усе зберігається автоматично в цьому браузері.
- Збереження трафарету у файл `*.sylianka.json` і відкриття з файлу — для резервних копій.
- «Скасувати» і «Повторити» (Ctrl+Z / Ctrl+Y, працює з будь-якою розкладкою).
- Сітка будь-якого розміру: ромбів у висоту та в ширину (до 400 з кожного боку).
- 3 або 4 бісерини на сторону ромба (разом із вузловими).
- Розфарбовування кліком і протягуванням мишею, гумка, дзеркальне фарбування.
- Підрахунок бісеру за кодами кольорів, заміна одного кольору іншим на всьому трафареті, заливка всіх порожніх бісерин.
- Друк з таблицею бісеру (код, назва, кількість) або лише трафарету без тексту, один чи два трафарети на аркуші A4.

Кольори каталогу обчислено з офіційних фото Preciosa, тож на екрані вони приблизні — орієнтуйтеся на код.

## Розробка

```bash
npm install
npm run dev      # локальний сервер
npm run build    # збірка в dist/
```

Кожен push у гілку `main` збирає й публікує сайт на GitHub Pages (`.github/workflows/deploy.yml`).

Каталог кольорів: сирі дані — `data/preciosa-10-0.txt`, з них `npm run catalog` генерує `src/data/preciosa.ts`
(українські назви, групи за кольором, порядок від світлих до темних).
