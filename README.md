# Трафарет силянки

Програма для трафаретів силянок: сітка з ромбів, розфарбовування бісерин кольорами Preciosa 10/0,
підрахунок бісеру, друк і позначення нанизаних бісерин під час плетіння.
Працює в браузері, встановлюється як програма (PWA) і працює без інтернету.

**Адреса:** https://binyachovo.github.io/sylianka/

## Можливості

### Панелі
- Угорі праворуч: «Мої трафарети», «Експортувати» (зберегти у файл чи картинкою) і «Друк» (усі налаштування
  друку у спливаючому вікні).
- Панель малювання — групи одна під одною: «Кольори трафарету», «Розміри», «Дзеркало й повтор», «Інструменти».

### Сітка
- «Розміри»: ромбів у висоту й у ширину (до 400 з кожного боку, до 12 000 ромбів разом
  для 2–4 бісерин на сторону, менше для більших комірок) і «Бісерин на сторону ромба».
- Від 2 до 10 бісерин на сторону ромба (разом із вузловими; 2 — лише вузлові); візерунок і позначки плетіння
  для кожної кількості зберігаються окремо. Що більші комірки, то менший найбільший розмір трафарету
  (щоб не гальмувало), а номери ромбів і рядів — більші.
- Масштаб на екрані: «−», «+», «Весь трафарет», «Авто».
- «Видалити ряд» і «Видалити стовпець» (група «Інструменти»): увімкніть і клікніть по трафарету — ряд чи стовпець
  під мишею (його заздалегідь підсвічує червона смуга) видаляється, а решта візерунка зсувається вгору чи ліворуч.
  Разом зсуваються позначки плетіння й проміжки, для всіх кількостей бісерин на сторону. Вузлові бісерини
  на межі лишаються від верхнього (лівого) сусіда. «Скасувати» повертає; Esc чи вибір кольору вимикає режим.
- «Видалити рядок» (група «Інструменти»): видаляє один рядок бісерин, а не цілий ромб. Клік по рядку бісерин сторін —
  він зникає по всій довжині, а ромби цього ряду стають нижчими: на їхніх верхніх (чи нижніх) сторонах на бісерину
  менше, решта трафарету не змінюється. Так можна і змінити форму силянки, і підправити візерунок. Вузлові рядки
  не видаляються — на них тримаються ромби (цілий ряд — «Видалити ряд»). Діє для візерунка з поточною кількістю
  бісерин на сторону; «Скасувати» повертає рядок разом із кольорами й позначками плетіння.
- Проміжки для вигляду між будь-якими рядками чи стовпчиками бісерин: клік у смузі з номерами — згори між
  стовпчиками, зліва між рядками (пунктир показує місце, повторний клік прибирає). Бісерини й нитки
  не змінюються; проміжки видно на екрані, у плетінні, на мініатюрі й на папері.

### Кольори
- Каталог Preciosa 10/0 (круглий рокайль, артикули 311-19001 і 331-19001) — 1 372 кольори з кодами,
  українськими назвами й описом Preciosa. Пошук за кодом (напр. `23980`) або назвою, групи за кольором.
- Кольори трафарету для швидкого вибору: код видно біля кожного кольору — у панелі, у каталозі,
  у підрахунку й у підказці над бісериною.
- «Мої кольори»: свій відтінок, своя назва й необов'язковий код; зберігаються для всіх трафаретів
  і потрапляють у файл трафарету.

Кольори каталогу обчислено з офіційних фото Preciosa, тож на екрані вони приблизні — орієнтуйтеся на код.

### Малювання
- Клік і протягування мишею, гумка, «Заливка» — клік заливає всю область бісерин того самого кольору,
  з'єднаних нитками (з гумкою — стирає її).
- Дзеркала «верх–низ» і «ліво–право» (можна разом) і «Повтор кожні N ромбів» — бісерина фарбується
  одразу в усіх повторах візерунка; осі й межі повторів видно пунктиром. Діють і для заливки.
- «Розмножити…» — візерунок вибраних ромбів копіюється праворуч до кінця трафарету.
- Підрахунок бісеру за кодами, заміна одного кольору іншим на всьому трафареті, заливка всіх порожніх бісерин.
- «Купувати»: скільки грамів бісеру кожного кольору й разом, із запасом 0–30 % на брак (рахуємо ≈ 90 бісерин
  Preciosa 10/0 в грамі — за даними продавців: близько 1 800 бісерин на 20 г, 2 600 на 30 г; це приблизно).
- «Скасувати» й «Повторити» — для будь-якої дії малювання, зокрема заливки, «Розмножити», проміжків
  і видалення рядів, стовпців чи рядків бісерин.

### Плетіння
- Нанизану бісеринку позначають кліком або протягуванням мишею; порядок позначення — її номер у наборі.
- Нанизані приглушуються, остання підсвічена («Показати, де зупинилися»), лічильник «нанизано N з M»,
  прогрес за кожним кольором, «Скинути позначки».
- «Показувати шлях набору» — лінія через нанизані бісерини в порядку позначення, стрілки напрямку
  й номер першої та кожної десятої.
- Окреме «Скасувати» / «Повторити» для позначок; підказка над бісериною — номер, код і колір.

### Трафарети й файли
- «Мої трафарети»: новий, відкрити, перейменувати, дублювати, видалити; мініатюри й прогрес плетіння.
  Усе зберігається автоматично в цьому браузері.
- «Експортувати» → «Зберегти у файл»: трафарет у файл `*.sylianka.json`; відкривається через «Мої трафарети» →
  «Відкрити з файлу».
- «Резервна копія» — усі трафарети й «Мої кольори» одним файлом; відновлюється через «Відкрити з файлу»
  (нічого не видаляє, наявні трафарети оновлює лише новішими). Робіть її час від часу: дані браузера
  можуть зникнути, наприклад після очищення історії.

### Друк
Кнопка «Друк» угорі праворуч відкриває спливаюче вікно з налаштуваннями й кнопкою «Друкувати…».
- З таблицею бісеру (код, назва, кількість) або «лише трафарет, без тексту».
- «Вмістити на аркуш» (можна дві копії на аркуші) або смугами з бісеринками заданого розміру (2,3–6 мм):
  довгий трафарет ділиться на смуги й аркуші з номерами ромбів, по змозі — саме на проміжках.
- Вікно «Друк» заздалегідь пише, скільки вийде аркушів і якого розміру бісеринки,
  зокрема чи таблиця бісеру перейде на окремий аркуш.
- Осі дзеркал, межі повторів, позначки плетіння й шлях набору на папір не потрапляють.

### Картинка
- «Експортувати» → «Зберегти картинкою» — PNG, щоб надіслати трафарет у месенджері: з назвою, номерами ромбів
  і рядів та списком кольорів (кількість і грами); «Картинкою без тексту» — сам трафарет.

### Клавіші
| Клавіша | Дія |
|---|---|
| 1–9 | кольори трафарету |
| E | гумка |
| F | заливка |
| Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) | скасувати / повторити |
| Esc | закрити спливаюче вікно, вимкнути видалення ряду чи стовпця, вийти з «лише трафарет» |

Клавіші працюють з будь-якою розкладкою.

### Інше
- Швидко працює й на довгих трафаретах (десятки тисяч бісерин; найбільший — понад 120 000).
- Нова версія програми ставиться за кнопкою «Оновити», без раптового перезавантаження.

## Файл трафарету

JSON з `"app": "sylianka"` і `"format": 2` (або 3, якщо в трафареті видалено рядки бісерин). У `project`: `name`, `rows`, `cols`, `side`, `palette`
(ідентифікатори кольорів: `p:<код>` — Preciosa, `u:<…>` — свій колір), `fills` і `woven` окремо для кожної кількості
бісерин на сторону (ключ бісерини — координати ґратки, напр. `"2.000,1.000"`), `gaps` — проміжки
`{ unit: 2520, x, y }` (після якої лінії бісерин, координата ґратки в 1/2520 кроку — так кожна лінія має ціле
положення для будь-якої кількості бісерин на сторону від 2 до 11; межа ромбів j — це 5040·j),
`repeat` — крок повтору в ромбах, `shape` — окремо для кожної кількості бісерин на сторону список бісерин
на сторону для половин рядів (верхня половина ряду 1, нижня, верхня ряду 2…; чого немає — як `side`).
Поруч — `colors`: дані своїх кольорів. Резервна копія має
`"kind": "backup"` і список `projects`. Старіші файли (кольори HEX, проміжки номерами ромбів чи в шостих частках ґратки) відкриваються
й переводяться автоматично.

## Розробка

```bash
npm install
npm run dev      # локальний сервер
npm test         # тести логіки (геометрія, проміжки, дзеркала й повтор, видалення рядів, стовпців і рядків бісерин, друк смугами, грами, перевірка даних)
npm run build    # перевірка типів і збірка в dist/
```

Кожен push у гілку `main` запускає тести, збирає й публікує сайт на GitHub Pages
(`.github/workflows/deploy.yml`).

Каталог кольорів: сирі дані — `data/preciosa-10-0.txt`, з них `npm run catalog` генерує `src/data/preciosa.ts`
(українські назви, групи за кольором, порядок від світлих до темних).
